# Jimmy Bridge

Jimmy Bridge is a governed local browser-control bridge for Gemini/Antigravity on Windows.

## Release model

Source and tests are canonical in GitHub. Compiled Windows installers are published as GitHub Release assets, not committed to the repository.

Current private-beta candidate: `v0.4.5`.

Release SHA-256: `DF488B6ACEE1F7E7A8687A8FC5487E50B16D04C4E8448BEEA1B61EF3F1D31647`

Protected actions require independent local-human approval. The model cannot authorize its own protected action.
